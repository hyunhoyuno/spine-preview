# 노출사철 책 미리보기 · SpineCalc

노출사철제본(exposed section-sewn binding)으로 책을 만들 때,
**등에 드러나는 접지면을 실제 내지에서 잘라 붙여 제본된 책을 미리 보여 주는 도구**입니다.

두 부분으로 되어 있습니다.

| | 무엇 |
|---|---|
| **웹 미리보기** — [`index.html`](index.html) | 내지 PDF + 세팅을 넣으면 제본된 책을 3D로 세워 보여 줍니다 |
| **InDesign 스크립트** — [`indesign/SpineCalc.jsx`](indesign/SpineCalc.jsx) | 책등 좌표를 계산하고, 책등 그림을 대수 단위로 잘라 지면에 배치합니다 |

---

## 왜 필요한가

노출사철제본은 등을 감싸지 않아 각 대수(signature)의 접지면이 그대로 드러납니다.
이 등면은 사실상 **각 대수 겉장의 접힌 부분이 옆으로 늘어선 하나의 캔버스**이고,
여기에 그림을 얹으면 책을 덮었을 때만 완성되는 그래픽이 됩니다.

문제는 이 캔버스가 페이지 위에는 존재하지 않는다는 점입니다. 디자이너는

- 등에 노출되는 페이지가 정확히 몇 쪽인지
- 그 페이지의 안쪽 여백 중 몇 mm가 실제로 보이는지
- 종이·평량·대수 구성에 따라 그 값이 어떻게 달라지는지

를 매번 손으로 계산하고 더미북으로 검증해야 합니다. 틀리면 인쇄 후엔 되돌릴 수 없습니다.

---

## 웹 미리보기 쓰는 법

`index.html`을 브라우저로 열고 두 파일을 끌어다 놓으면 끝입니다.

1. **내지 PDF** — InDesign에서 *페이지 단위*(스프레드 아님)로 내보낸 내지
2. **세팅** — SpineCalc의 `⑤ 좌표 JSON` (또는 `settings.ini` 프리셋)

세팅 없이 PDF만 놓아도 16p 대수 · 미색모조 100g으로 가정해 보여 줍니다.
불러온 값은 좌측 하단에 작게 표시됩니다.

- **드래그** 회전 · **휠** 확대 · **Shift+드래그** 이동
- **실** 토글과 색(생사 / 검정 / 빨강 / 파랑)
- **책등 전개** 를 켜면 등면을 평평하게 펼쳐 대수 경계와 함께 확인할 수 있습니다

모든 처리는 브라우저 안에서만 일어납니다. PDF는 어디로도 전송되지 않습니다.

## InDesign 스크립트 쓰는 법

`indesign/SpineCalc.jsx`를 스크립트 패널에 넣고 실행합니다.
자세한 내용은 [`indesign/README.md`](indesign/README.md).

```
① 책등 아트워크 캔버스 문서 만들기   → 책등 크기의 새 문서 (대수 가이드 포함)
② 현재 문서에 노출영역 가이드 표시   → 노출 페이지의 안쪽 여백에 가이드 + 본문 침범 경고
③ 책등 이미지 대수 분할 배치         → 그림을 대수 단위로 잘라 각 페이지에 자동 배치
④ 리포트 저장 (.csv)
⑤ 좌표 JSON 내보내기                 → 웹 미리보기에 넣는 파일
```

## 계산 로직

**등 노출 페이지** — 각 대수의 첫 쪽과 마지막 쪽.
16p 대수라면 `1·16`, `17·32`, `33·48` … 접지된 겉장의 *바깥면*이 곧 등면입니다.

**대수 두께**

```
t = (대수 페이지 수 ÷ 2) × 낱장 두께 + 실 보정
```

**페이지에서 보이는 여백**

```
W = (t ÷ 2) × 접지 곡률계수      (1.0 = 눌린 각접지, 1.57 = 반원 접지)
```

**이미지 분할 매핑**

| 대상 | 슬라이스 | 페이지에서의 위치 | 방향 |
|---|---|---|---|
| 대수 첫 쪽 (홀수·recto) | `[x0, mid]` | 페이지 **왼쪽** 끝 W mm | 반전 |
| 대수 마지막 쪽 (짝수·verso) | `[mid, x1]` | 페이지 **오른쪽** 끝 W mm | 반전 |

두 쪽 모두 반전인 이유는 종이가 접지를 돌아 나오면서
페이지 좌표와 등면 좌표의 진행 방향이 뒤집히기 때문입니다.
접지선이 `mid`에, 바깥 경계가 `x0`/`x1`에 대응합니다.

## 알아 둘 제약

- **가로 해상도 = 대수 개수.** 208쪽·16p 대수면 세로 밴드 13개가 전부입니다.
  사진 같은 계조 이미지는 원리적으로 성립하지 않고, 대비 강한 도형·타이포·패턴이라야 읽힙니다.
- **실측 보정 없이는 맞지 않습니다.** 용지 공칭 부피는 롯트마다 ±10% 흔들립니다.
  더미북을 만들어 등두께를 재고 SpineCalc의 `실측값으로 계수 역산`을 거치세요.
- **크리핑(creep) 미반영** — 두꺼운 용지 + 32p 대수에서 오차가 커집니다.
- **실 가림** — 사철 실이 지나는 자리는 그림이 덮입니다. 미리보기의 실 표시로 확인하세요.
- **양면 노출** — 안쪽 여백의 잉크는 책을 펼쳤을 때 본문에서도 보입니다.

## 빌드

`index.html`은 [PDF.js](https://mozilla.github.io/pdf.js/)를 인라인한 단일 파일입니다.
외부 요청 없이 혼자 동작하므로 파일 하나만 열어도 됩니다.

고치려면 [`src/spine-preview.src.html`](src/spine-preview.src.html)을 수정하고

```bash
cd src && python3 build.py
```

`build.py`는 PDF.js를 끼워 넣어 `index.html`을 다시 만듭니다.
(PDF.js 파일 경로는 `build.py` 안의 `SC` 변수에서 지정합니다.)
