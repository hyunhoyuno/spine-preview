# SpineCalc v2.2 — 노출사철제본 책등 계산기 (InDesign 스크립트)

계획서 3.1 MVP 범위를 InDesign 위에서 구현한 도구.

> **v2.1 — 창이 palette로 바뀌었습니다.**
> InDesign은 ScriptUI **dialog**(모달)가 떠 있는 동안 문서 생성·수정과 `scriptPreferences` 변경을
> 전부 거부합니다. 그래서 v2에서는 실행 버튼을 누르면
> `다른 대화 상자 또는 경고가 활성화되어 있으므로 요청을 처리할 수 없습니다` 로 실패했습니다.
> **palette**(비모달)로 바꿔 해결했고, 덕분에 창을 띄워둔 채 문서를 오가며
> ②③을 반복 실행할 수 있습니다. 창을 살리기 위해 `#targetengine "session"` 이 함께 필요합니다.
>
> 이전 버전을 실행해 창이 떠 있었다면, **그 창을 먼저 닫아야** 새 버전이 동작합니다.
> 닫히지 않으면 InDesign을 클릭해 활성화한 뒤 `esc`.

## 설치

1. InDesign → `창 > 유틸리티 > 스크립트`
2. 패널의 **User** 폴더 우클릭 → `Finder에 표시`
3. 열린 폴더의 `Scripts Panel` 안에 `SpineCalc.jsx` 복사
4. 스크립트 패널에서 더블클릭

```bash
open ~/Library/Preferences/Adobe\ InDesign/Version\ 20.0/ko_KR/Scripts/Scripts\ Panel
```
(버전·언어 폴더는 설치본에 맞게 다릅니다. 없으면 3번 방법으로 찾으세요.)

## 설정 유지 · 프리셋 (v2.2)

입력값은 **자동으로 저장**됩니다. 창을 닫았다 다시 열어도 마지막에 쓰던 값 그대로 시작합니다.
저장 시점은 ① 계산할 때마다 ② 실행 버튼을 누를 때 ③ 창을 닫을 때입니다.

**프리셋** 패널(맨 위)에서 작업별 설정을 이름 붙여 저장·호출할 수 있습니다.

| 버튼 | 동작 |
|---|---|
| **현재 값으로 저장** | 이름을 물어보고 지금 입력값 전체를 프리셋으로 저장. 같은 이름이면 덮어쓸지 확인 |
| **불러오기** | 선택한 프리셋을 전 항목에 적용하고 즉시 재계산 |
| **삭제** | 선택한 프리셋 삭제 (확인 후) |

저장 대상은 용지·평량·두께(직접 입력 포함)·총 페이지·대수 구성·실 보정·대수 간격·곡률계수·판형·재단물림·도련 포함 여부·실측값 **전부**입니다.

설정 파일 위치:

```bash
open ~/Library/Application\ Support/SpineCalc/
```

`settings.ini` 는 사람이 읽는 `key=value` 형식이라 직접 열어 편집하거나, 다른 맥으로 복사해 프리셋을 옮길 수 있습니다.

```ini
[last]
paper=미색모조
gsm=100
total=208
…
[preset:한양대 도록]
paper=인스퍼 M
gsm=130
total=312
…
```

> 파일을 지우면 기본값으로 되돌아갑니다. 단 **팔레트가 열려 있는 상태에서 지우면 창을 닫을 때 다시 쓰입니다** — 창을 먼저 닫고 지우세요.

## 사용 순서

### 1. 용지
종류·평량 선택 → 낱장 두께 자동 계산. `직접 입력` 체크 시 실측 두께 사용.

### 2. 대수 / 제본
- **총 페이지** — 4의 배수. `현재 문서` 버튼으로 열린 문서에서 페이지 수·판형을 함께 가져옵니다.
- **대수 페이지** — 8/16/32 또는 `수동 입력`(`16,16,16,8`)
- **실 보정 /대수** — 사철 실이 만드는 대수당 추가 두께 (기본 0.25mm)
- **대수 간격** — 노출사철에서 대수 사이가 벌어지는 양 (기본 0)
- **접지 곡률계수** — 접힌 부분이 페이지 여백을 얼마나 소모하는지
  `1.0` 완전히 눌린 각접지 / `1.57` 반원 접지(기본, 노출사철에 근접)

### 3. 판형 / 재단
판형 W×H, 상하 재단물림, 그리고 **아트워크에 도련이 포함되어 있는지** 체크.
①에서 만든 캔버스를 *도련 포함*으로 내보냈다면 체크 유지.

### 4. 실측 보정 ← 인쇄 전 필수
더미북 실제 등두께를 재서 입력 → `실측값으로 계수 역산`.
오차가 실 보정계수로 흡수되고 즉시 재계산됩니다. **이 과정 전 수치는 참고용입니다.**

## 실행 버튼

| 버튼 | 동작 |
|---|---|
| **계산하기** | 대수별 표 + 책등 총 두께 + 노출 페이지 산출 |
| **① 캔버스 문서 만들기** | `책등두께 × 판형높이` 새 문서. 파랑=대수 경계, 빨강=접지 중심 가이드, 세로 대수 라벨, 앞/뒤표지 방향 표시, 우측 범례. 가이드·라벨 레이어는 잠기고 `책등 아트워크` 레이어가 활성화됩니다. |
| **② 노출영역 가이드 표시** | 본문 문서의 노출 페이지마다 안쪽 여백에 빨간 박스. **본문 안쪽 여백이 노출 폭보다 좁으면 해당 페이지를 목록으로 경고합니다.** |
| **③ 이미지 대수 분할 배치** | 아트워크(PDF/AI/PSD/TIF/PNG/JPG)를 대수 두께에 비례한 가변 폭으로 잘라 각 페이지에 배치. 접지 방향에 맞춰 좌우 반전 포함. |
| **④ 리포트 저장 (.csv)** | 사양 요약 + 대수별 전체 수치 |
| **⑤ 좌표 JSON 내보내기** | 페이지별 슬라이스 좌표 — Illustrator/외부 툴 연동용 |

②③은 실행할 때마다 해당 레이어를 **비우고 다시 생성**하므로 반복 실행해도 중복이 쌓이지 않습니다.

## 계산 로직

**등 노출 페이지** — 각 대수의 첫 쪽과 마지막 쪽. 16p 대수면 `1·16`, `17·32`, `33·48` …
접지된 겉장의 *바깥면*이 곧 등면입니다.

**대수 두께**
```
t = (대수 페이지 수 ÷ 2) × 낱장 두께 + 실 보정
```

**페이지 노출 여백**
```
W = (t ÷ 2) × 접지 곡률계수
```

**등면 좌표계** — 앞표지쪽 `0`에서 대수 두께를 누적. `x0~x1`이 밴드, `mid`가 첫 쪽/마지막 쪽 분기선.

**이미지 분할 매핑**

| 대상 | 슬라이스 | 페이지에서의 위치 | 방향 |
|---|---|---|---|
| 대수 첫 쪽 (홀수·recto) | `[x0, mid]` | 페이지 **왼쪽** 끝 W mm | 반전 |
| 대수 마지막 쪽 (짝수·verso) | `[mid, x1]` | 페이지 **오른쪽** 끝 W mm | 반전 |

두 페이지 모두 반전인 이유: 종이가 접지를 돌아 나오면서 페이지 좌표와 등면 좌표의 진행 방향이 뒤집히기 때문입니다. 접지선(페이지의 등쪽 끝)이 `mid`에, 바깥쪽 경계가 `x0`/`x1`에 대응합니다.

## v2에서 고친 것

이전 버전의 실제 결함:

1. **단위 복원 버그** — 캔버스 생성 시 저장/복원을 두 번 겹쳐 호출해 사용자의 원래 측정 단위가 mm로 덮어써졌습니다. 스택 방식으로 교체.
2. **배치 중 대화상자 폭주** — `userInteractionLevel` 설정이 없어 26개 슬라이스마다 PDF/PSD 가져오기 옵션 창이 떴습니다. `NEVER_INTERACT`로 감쌌습니다.
3. **라벨 회전 위치 어긋남** — `rotationAngle` 대신 `transform()` + TOP_LEFT 기준 시계방향 90°로 교체해 위치를 결정론적으로 만들었습니다. 라벨도 본문 영역 밖(작업대)으로 뺐습니다.
4. **문서 여백 설정 무효** — `documentPreferences` 대신 실제 페이지의 `marginPreferences`에 적용.
5. **도련 처리 누락** — 아트워크에 도련이 포함됐는지 선택하는 옵션이 없어 무조건 늘어났습니다. 체크박스 + PDF Crop 연동 추가.
6. **재실행 시 중복 누적** — 레이어를 비우지 않고 계속 쌓였습니다. 재생성 방식으로 교체.
7. **용지 전환 후 두께 미갱신** — `직접 입력`을 한 번 쓰면 이후 용지를 바꿔도 두께가 그대로 남았습니다.
8. **입력 불일치 무검사** — 문서 페이지 수/마주보기 여부를 확인하지 않고 배치해 엉뚱한 페이지에 얹힐 수 있었습니다. 사전 검사 추가.
9. **혼합 대수 요약 오류** — 노출 여백을 첫 대수 값 하나로만 표시했습니다. 최소~최대 범위로 교체.
10. 누락 기능 추가 — JSON 좌표 출력, 본문 안전영역 침범 경고, 판형 폭 입력.

**검증한 것**
- ES3 구문 검사 통과
- 계산 코어를 분리 실행: 208p/16p/0.13mm → 13대, 대수 1.290mm, 책등 16.77mm, 노출 26쪽, 여백 1.013mm (계획서 부록과 일치)
- 슬라이스 연속성: 26개 조각 합 = 책등 총 두께, 빈틈·중복 0
- 배치 역산: 반전 후 접지선이 `mid`에, 바깥 경계가 `x0`/`x1`에 정확히 대응. 인접 대수 경계도 연속
- 실측 역산: 임의 실측값 입력 → 재계산 결과가 그 값과 정확히 일치
- 대수 나머지 편성: 200/196/212/164p 모두 합계 일치

## InDesign 실기 검증 (2026-08-27, InDesign 2026 / 21.0.0)

`책등계산기.indd` (148×210mm, 208p, 마주보기, 도련 3mm)에서 전 기능 실행.

| 항목 | 결과 |
|---|---|
| 계산 | 13대 · 책등 16.77mm · 대수 1.290mm · 노출여백 1.013mm — 사전 계산치와 일치 |
| ② 노출영역 가이드 | 26개 생성. recto는 페이지 좌측 0mm, verso는 우측 0mm, 폭 1.013mm, 높이 216mm(도련 포함) |
| ① 캔버스 문서 | 16.77×210mm, 가이드 27개, 라벨 15개, 아트 레이어 활성 |
| ③ 이미지 분할 배치 | 26조각. **전 조각의 접지선·바깥경계 좌표와 반전 상태를 되읽어 26/26 통과** |
| 재조립 대조 | 배치된 26조각을 책등 순서로 되돌려 재조립 → 원본 아트워크와 일치 (톤 램프·대각선 연속성·기준선 위치·방향 전부) |

`flipItem`은 프레임 경계를 유지한 채 내용만 반전시킵니다. 우려했던 부분은 문제 없었습니다.

**실기에서만 드러난 버그 2개 (수정 완료)**

11. **캔버스 생성 자체가 실패했다** — 새 문서의 기본 여백(좌우 각 20mm)이 책등 폭(16.77mm)보다 넓어 `pageWidth` 설정이 `데이터가 범위를 벗어났습니다`로 거부됐습니다. 여백을 먼저 0으로 내리도록 순서를 바꿨습니다.
12. **마스터 스프레드 여백** — 문서·페이지 여백만 0으로 내려선 부족했고, 모든 마스터 스프레드 페이지까지 내려야 통과했습니다.

## UI 없이 호출하기 (자동화·배치 처리용)

`$.global.SPINECALC_NO_UI = true` 로 두고 파일을 eval 하면 대화상자 없이 계산 엔진만 올라옵니다.

```javascript
$.global.SPINECALC_NO_UI = true;
var f = new File("/…/SpineCalc.jsx");
f.encoding = "UTF-8"; f.open("r"); eval(f.read()); f.close();

var SC    = $.global.SpineCalc;
var sigs  = SC.composeSignatures(208, 16);            // → [16,16,…] 13개
var spine = SC.buildSpine(sigs, 0.13, 0.25, 0, 1.57); // 두께·실보정·간격·곡률

SC.markExposedAreas(app.activeDocument, spine, 3);
SC.placeSpineArt(app.activeDocument, spine, new File("art.pdf"), 3, 1.57, true);
```

노출 API: `PAPERS` `paperThickness` `composeSignatures` `parseManualSignatures` `buildSpine`
`makeSpineCanvas` `markExposedAreas` `placeSpineArt` `buildReport` `buildJSON` `stripBounds`

### 용지 추가

`SpineCalc.jsx` 상단 `PAPERS` 배열만 고치면 됩니다.

```javascript
{ name: "용지 이름", bulk: 1.30, gsm: [100, 120, 150] },
```

실측 두께를 안다면 역산: `bulk = 두께(mm) × 1000 ÷ 평량`
예) 130g 실측 0.18mm → `0.18 × 1000 ÷ 130 = 1.38`

## 남은 제약 (계획서 3.2 / 5장)

- **가로 해상도 = 대수 개수.** 208쪽·16p면 밴드 13개. 사진적 이미지는 성립하지 않습니다.
- **크리핑(creep) 미반영.** 두꺼운 용지 + 32p 대수에서 오차가 커집니다.
- **실 가림 미반영.** 사철 실이 지나는 구간은 그림이 덮입니다.
- **양면 노출.** 안쪽 여백의 잉크는 펼쳤을 때 본문에서도 보입니다 — ②의 경고로 확인하세요.
- **페이지 번호 = 문서 물리 순서.** 섹션 번호 매기기를 쓰는 문서에서는 1번째 페이지를 p.1로 봅니다.
